Under the hood

System architecture

How the disease detection, yield prediction, and recommendation modules are actually built and trained.

01

Disease detection — CNN, transfer learning

EfficientNet-B0 (ImageNet-pretrained), fine-tuned on 2,289 labelled black pepper images across six classes. 97% held-out test accuracy. Backbone frozen; only the classifier head trained on this dataset.

02

Explainability — Grad-CAM & SHAP

Grad-CAM overlays a heatmap on the input image showing which pixels drove the CNN's class decision. For the yield model, SHAP values give per-feature, per-prediction contribution.

03

Yield prediction — gradient-boosted trees

XGBoost regression trained on district-year panel data from Kerala and Karnataka (2001–2022): vine age, soil type, previous yield, rainfall, temperature, and disease severity.

04

Weather ingestion

Live and historical data pulled from Open-Meteo, keyed to farm coordinates. Rolling rainfall/temperature aggregates feed the yield model and trigger fungal-risk alerts.

05

Recommendation engine

Rules layer mapping {disease, severity, soil, rainfall} → fungicide/pesticide choice and dose window, irrigation frequency, and NPK + organic manure schedule, sourced from ICAR-IISR extension guidelines.

06

Stack

FastAPI backend serving the CNN and XGBoost models locally; this static frontend calling those endpoints; Open-Meteo for live weather.
